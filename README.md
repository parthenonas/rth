## 🛠 Development Environment

To ensure a consistent development experience and simplify dependency management, project RTH provides a pre-configured development box based on Debian 13.3.0. This environment includes all necessary tools such as Incus, ZFS, Rust, and Node.js (via fnm).

### Prerequisites

Ensure the following software is installed on your host machine:

- VMware Workstation Pro (Version 25H2 or newer).
- Vagrant with the VMware Desktop provider plugin.
- Visual Studio Code with the Remote Development extension pack. 

### Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com
    cd rth
    ```
1. Initialize the development VM:
    ```bash
    # Standard headless start
    vagrant up

    # Or start with a GUI
    vagrant up --gui
    ```
1. Connect via VS Code Remote-SSH:
    - Open the Command Palette (`Ctrl+Shift+P`)
    - Select Remote-SSH: Connect to Host...
    - Enter vagrant@127.0.0.1 or use the configuration generated by `vagrant ssh-config`.
    - The project repository is automatically mounted at `/home/vagrant/rth` inside the virtual machine. 

### Customizing the Build (Packer)

If you need to modify the base environment or update the pre-installed tools, the build templates are located in the `./packer` directory.

Refer to the Packer Documentation for detailed build instructions.
Run `make build` within the /packer directory to generate a new Vagrant box.
