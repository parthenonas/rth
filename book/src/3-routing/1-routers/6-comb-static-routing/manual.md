# Инструкции

## Предварительная подготовка лабораторного окружения

1. Запустить виртуальную машину **AstraLinuxCN-GNS3**
2. Запустить прилагаемый проект в среде симуляции сети **GNS3**

Для запуска проекта в **GNS3** необходимо:

- [↓ Загрузить файл проекта comb-static-routing.gns3project](./comb-static-routing.gns3project){download}
- Скопировать файл проекта `comb-static-routing.gns3project` в виртуальную машину
- Импортировать файл `comb-static-routing.gns3project` в GNS3
- Запустить все узлы проекта

## Планирование адресного пространства корпоративной сети

Разделите адресное пространство корпоративной сети на подсети с учетом потребности подразделений.

## Настройка устройств корпоративной сети

Выполните настройку устройств компьютерной сети c учетом их текущей конфигурации.

## Определение технического состояния корпоративной сети

Определите техническое состояние компьютерной сети.
Сделайте выводы.
