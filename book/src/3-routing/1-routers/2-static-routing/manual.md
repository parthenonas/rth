## Инструкции

### Предварительная подготовка лабораторного окружения

1. Запустить виртуальную машину **AstraLinuxCN-GNS3**
2. Запустить прилагаемый проект в среде симуляции сети **GNS3**

Для запуска проекта в **GNS3** необходимо:

- [↓ Загрузить файл проекта static-routing.gns3project](/3-routing/1-routers/2-static-routing/static-routing.gns3project){download}
- Скопировать файл проекта `static-routing.gns3project` в виртуальную машину
- Импортировать файл `static-routing.gns3project` в GNS3
- Запустить все узлы проекта

### Настройка оконечного устройства PC1

#### Шаг 1. Определить текущую конфигурацию хоста PC1

На этом шаге необходимо определить название, состояние и существующую IP-конфигурацию сетевых интерфейсов хоста.
Это возможно сделать при помощи известной команды `ip address show`. Примерный результат выполнения команды представлен далее:

::: details Результат выполнения команды
```sh
# ip address show
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN group default qlen 1000
    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
    inet 127.0.0.1/8 scope host lo
       valid_lft forever preferred_lft forever
    inet6 ::1/128 scope host
       valid_lft forever preferred_lft forever
5: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc pfifo_fast state UNKNOWN group default qlen 1000
    link/ether da:8e:1c:18:5d:46 brd ff:ff:ff:ff:ff:ff
    inet6 fe80::d88e:1cff:fe18:5d46/64 scope link
       valid_lft forever preferred_lft forever
```
:::

В текущей конфигурации **PC1**:
- имеет сетевой интерфейс eth0 в административном состоянии &ndash; **включен** (`<BROADCAST,MULTICAST,UP,LOWER_UP>`)
- сетевой интерфейс eth0 не имеет IP-конфигурации

#### Шаг 2. Задать IP-адрес и маску подсети на интерфейсе **eth0** хоста PC1

В этом задании представлен основной способ настройки IP на хоста по управлением ОС Linux без графического интерфейса.
Суть способа состоит в записи IP-конфигурации в текстовый файл `/etc/network/interfaces`.
Для этого необходимо:
- открыть этот файл в текстовом редакторе **nano** выполнив команду `nano /etc/network/interfaces`
- записать необходимую IP-конфигурацию
- сохранить и закрыть текстовый файл
- перезапустить сетевую службу в ОС Linux одним из доступных способов.

Выполните команду `nano /etc/network/interfaces` для открытия текстового файла.

::: warning Предупреждение
Консоль хоста **PC1** имеет текущего пользователя **root**.
Таким образом файл `/etc/network/interfaces` будет открыт от имени этого пользователя с правом на запись. Убедиться в этом можно проверив права доступа к файлу `ls -l /etc/network/interfaces`:

```sh
-rw-r--r-- 1 root root 435 Mar 18 14:08 /etc/network/interfaces
```

Если бы текущий пользователь консоли не имел бы права на запись этого текстового файла, тогда необходимо использовать команду `sudo nano /etc/network/interfaces`.
:::

Затем внесите следующую запись:

```sh
auto eth0
iface eth0 inet static
    address 192.168.31.2
    netmask 255.255.255.128
    gateway 192.168.31.1
```

Для записи введите `Ctrl+O`, **nano** предложит ввести имя записываемого файла, нажмите `Enter`, чтобы оставить прежнее имя.
Закройте текстовый редактор введя `Ctrl+X`.

Чтобы конфигурация из текстового файла стала действовать, необходимо перезагрузить сетевую службу в случае этого хоста при помощи команды `ifdown eth0 && ifup eth0`.
На хостах с системой инициализации  и управления службами **systemd** точнее использовать команду `sudo systemctl restart networking`.
